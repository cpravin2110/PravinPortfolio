MACHINE LEARNING & NLP

Real Estate Price Prediction & Recommendation | ML

✦ Built an end-to-end ML web app that predicts property prices, visualizes market trends and recommends similar apartments across 104 Gurgaon sectors, using ~3,500 cleaned property listings.

✦ Benchmarked 11 regression algorithms with 10-fold cross-validation and tested Ordinal, One-Hot and Target encoding plus PCA. Target-encoding the high-cardinality sector feature lifted CV R² from 0.842 (best PCA model) to 0.899, and a log1p transform on price handled skewness.

✦ Tuned XGBoost with GridSearchCV (192 combinations, 1,920 fits), reaching a CV R² of 0.906 and a hold-out MAE of about ₹10.8 lakh, then packaged preprocessing and model into a single scikit-learn Pipeline.

✦ Built a content-based recommender using cosine similarity (top 5 similar apartments within a chosen radius) and an interactive analytics dashboard, and deployed the app on Streamlit Community Cloud.
Stack: Python, Scikit-learn, XGBoost, Pandas, Plotly, Streamlit

YouTube Comment Sentiment Analysis | NLP

✦ Built an NLP web app that fetches live comments for any YouTube video through the YouTube Data API and classifies each as Positive, Neutral or Negative, with an interactive analytics dashboard.

✦ Trained on 1,032,064 labelled comments from 4,563 videos. Compared 7 classifiers using stratified 3-fold CV and tuned a TF-IDF (unigram + bigram, 100K features) + Logistic Regression pipeline with GridSearchCV, finding that linear models beat Random Forest on sparse text features.

✦ Final model reached 70.84% accuracy and 0.71 macro F1 on 206K unseen comments, beating the Naive Bayes baseline (66.3%). Training on the full dataset added about 3.5 points over a 100K-sample model, showing more data helped more than tuning.

✦ Dashboard includes sentiment distribution charts, word cloud, top positive/negative comments and CSV export, deployed on Streamlit Community Cloud.
Stack: Python, NLP, NLTK, Scikit-learn, Pandas, Streamlit
